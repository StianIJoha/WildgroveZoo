# Wildgrove Zoo

A cozy isometric zoo game for the browser, inspired by Zoomumba. Build enclosures, care for every animal, run shops for visitors, breed rare subspecies, go on safari and grow your land.

**Play:** open `index.html` in any modern browser. No install, no internet needed. Progress saves in that browser.

**Develop:** edit the files in `src/`, then run `node build.js` to rebuild `index.html`. Run `python tests/playthrough.py` to check nothing broke.

See `HANDOFF.md` for how everything works, known issues and ideas for what to build next.
