# Wildgrove Zoo

A cozy isometric zoo game for the browser, inspired by Zoomumba. Build enclosures, care for every animal, run shops for visitors, grant their wishes, breed rare subspecies, go on safari, join the weekly festival and grow your land through day and night.

**Play:** open `index.html` in any modern browser. No install, no internet needed. Progress saves in that browser; use Zoo → Zoo office → Save code & backup to move it to another device.

**Develop:** edit the files in `src/`, then run `node build.js` to rebuild `index.html`. Run `python tests/playthrough.py` to check nothing broke (set `PW_CHROMIUM` to a Chromium binary if Playwright's own browser isn't installed).

See `HANDOFF.md` for how everything works, known issues and ideas for what to build next.
